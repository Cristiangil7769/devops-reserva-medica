# 🏥 Servicio Web de Reserva de Horas Médicas - Proyecto DevOps

Este repositorio contiene la solución automatizada e infraestructurada para la plataforma web estática de reserva de horas médicas, orientada a estandarizar entornos de ejecución locales mediante Docker y Git.

## 🚀 Requisitos Previos
* Git instalado y configurado.
* Docker Desktop ejecutándose.
* Navegador Web.

## 🛠️ Instrucciones de Instalación y Ejecución

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/Cristiangil7769/devops-reserva-medica.git](https://github.com/Cristiangil7769/devops-reserva-medica.git)
